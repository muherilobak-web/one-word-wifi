One ordinary household noun that also happens to be a networking term — and the collision between the two meanings is the joke. In the house, the word names a familiar object that famously vanishes without a trace, leaving only one of a pair behind. On a network, the same word names a proxy that stands between you and the wider internet. The entry word is that noun: at home it is an everyday object, on the wire it is a go-between, and the joke is that both of them disappear on you without warning, just like home Wi-Fi.

## Run it

```sh
node main.ts
```

This writes the single-word entry to `/output/entry.txt` (no trailing newline).
